Calibration dot: Side 1, 3 steps inside the 45; 2 steps behind the front sideline. At 22.5 inches, this is x = 46.875 yd, y = 1.25 yd from the Side 1 goal line and front sideline.


Audio & timing
Counts are marching pulses. Use counts per beat if the written beat spans multiple marching pulses.
Markers align exact counts to audio and scale the tempo map between anchors. The audio clock drives the dots while music is attached.
A numeric title describes the whole phrase, including subsets. Marching finishes before the hold begins. Conflicting entries retain their existing interpolation until corrected below.
Early arrival is an approximation, not verified choreography. Select a marcher → Marcher timing to set exact step-off and marching counts.
Align sets to the music
Seek the preview to when this set is reached, then align. This adds an exact sync marker. Use two or more set anchors to correct slow or fast transitions.


Set order & transition counts
Total counts include marching and holding. March counts say how many counts are spent moving; the remaining counts hold at the destination. These phases can be edited independently. Each duration is the number of counts from the previous set into this set. Confirm this convention against your cards. Blank or conflicting durations block playback.
